# nvim

Stock [LazyVim](https://www.lazyvim.org), the same base Omarchy ships.

- **Ubuntu**: this whole folder is linked to `~/.config/nvim` (Tokyo Night).
- **Omarchy**: Omarchy's own LazyVim stays in place; only
  `lua/plugins/dashboard.lua` (the start page header) is linked from here.

Plugins install themselves on first launch.
